# Meu Portal de Notícias

Exercício de CSS: a página de um portal de notícias com seções de esportes, entretenimento, tecnologia e economia, cada uma com a sua cor.

## Como executar

Abra o arquivo `index.html` no navegador.

> As imagens das notícias ficam na pasta `imagens/`, que ainda não foi enviada para o repositório.

## Tecnologias

- HTML5
- CSS3 (Flexbox)
